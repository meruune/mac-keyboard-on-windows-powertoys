Close PowerToys, put `default.json` in `%localappdata%/Microsoft/PowerToys/Keyboard Manager/default.json`, and then restart PowerToys.

All shortcuts are defined in `Keymap.cs`, please refer to it for what's implemented and what is not. The app will generate a new `default.json` file in working directory If you want to reset your shortcuts, you can delete the `default.json` file and restart PowerToys.
